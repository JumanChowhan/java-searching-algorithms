🔎 Searching Algorithms in Java

A simple Java console-based program demonstrating two fundamental searching algorithms:

Linear Search

Binary Search

This project is designed for beginners who are learning Data Structures and Algorithms (DSA) using Java.

📌 Features

🔹 Linear Search implementation

🔹 Binary Search implementation

🔹 Menu-driven console interface

🔹 User-defined array size

🔹 User input for array elements

🔹 Displays the index when an element is found

🔹 Displays a message when an element is not found

🔹 Exit option

🧠 Algorithms
1. Linear Search

Linear Search checks each element one by one until the required element is found.

Time Complexity:

Best Case: O(1)

Average Case: O(n)

Worst Case: O(n)

Requirement: The array does not need to be sorted.

2. Binary Search

Binary Search repeatedly divides a sorted array into two halves to find the required element.

Time Complexity:

Best Case: O(1)

Average Case: O(log n)

Worst Case: O(log n)

Requirement: The array must be sorted.
